# 户型图编辑器 · 需求规格说明

| 项目 | 内容 |
|---|---|
| 文档版本 | v0.1（草案） |
| 编写日期 | 2026-11-05 |
| 适用项目 | HomeRoom（React + TypeScript + Vite + three.js） |
| 关联文档 | [户型编辑器-技术方案](./户型编辑器-技术方案.md) |

## 1. 背景与现状

HomeRoom 当前是一个「固定户型 + 可装修」的设计工具：

- 户型几何来自静态文件 `src/data/floorplan.json`，由 `src/lib/plan.ts` 直接导入。
- 用户只能编辑家具、房间名称、地面材料，以及按墙段拆除。
- 墙体使用数组下标 `w0 / w1 ...` 标识，增删墙体后拆除记录会错位。
- 2D/3D 渲染都依赖轴对齐矩形墙体，尚无墙体、门窗、房间的编辑能力。

因此，本需求的目标是把户型几何从「只读资源」升级为「可编辑、可持久化的文档」，并覆盖用户对空间布局的完整自定义诉求。

## 2. 目标

用户可以在 2D 平面图中自定义：

1. 墙体布局；
2. 房间数量与大小；
3. 窗户位置与尺寸；
4. 门的位置与尺寸；
5. 门的开启方向。

编辑结果需要实时同步到 3D 场景，并支持撤销、刷新持久化、导入导出。

## 3. 范围

### 3.1 本期范围

- 正交墙（水平 / 垂直），单楼层。
- 墙体增删改：画墙、移动、改长度、改厚度、改类型、删除。
- 房间由墙体围合自动识别，随墙体变化自动重算数量、大小、面积。
- 窗户、门、推拉门在墙体上插入、沿墙移动、改宽、删除。
- 门的铰链端与开启侧可切换，2D 开启弧线与 3D 门扇同步。
- 方案撤销/重做、本地持久化、JSON 导入导出、旧存档迁移。

### 3.2 本期不做

- 任意角度斜墙、弧墙。
- 与墙体无关的手动房间划分（开放式空间的逻辑分区）。
- 导入图片底图描图。
- 多楼层、结构计算、施工图输出。
- 3D 场景内的墙体编辑（3D 只做结果预览）。

以上能力可在后续版本扩展，数据模型已预留升级空间。

## 4. 用户角色与场景

| 角色 | 场景 |
|---|---|
| 装修用户 | 拿到原始户型后，调整房间分隔、扩大或缩小房间、改门窗位置。 |
| 设计师 | 快速搭建多房间方案，对比不同墙体与门窗布置。 |
| 演示用户 | 在 2D 编辑完成后切换 3D，检查空间关系和门开方向是否合理。 |

## 5. 功能需求

### FR-01 墙体布局编辑

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-01-1 | 画墙 | 在 2D 中按下并拖动，生成一段正交墙；显示实时预览与长度标注。 |
| FR-01-2 | 改长度 | 选中墙体后拖动端点手柄，长度实时变化并显示数值。 |
| FR-01-3 | 改厚度 | 拖动厚度手柄或在属性面板输入厚度。 |
| FR-01-4 | 移动墙体 | 拖动墙身整体平移，墙体依附的门窗随之移动。 |
| FR-01-5 | 改类型 | 属性面板可切换承重墙 / 外墙 / 隔墙 / 矮墙；类型影响颜色与 3D 高度。 |
| FR-01-6 | 删除墙体 | 删除选中墙体；依附门窗一并删除或按规则处理。 |
| FR-01-7 | 吸附 | 支持网格、墙端点、墙面、中点吸附；吸附时显示提示。 |
| FR-01-8 | 拆改保留 | 原有「拆改墙体」能力保留；墙体编辑后自动清理失效的拆改记录。 |

### FR-02 房间数量与大小

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-02-1 | 自动识别房间 | 墙体围合形成封闭区域后，自动生成房间。 |
| FR-02-2 | 快速建房 | 使用「房间」工具拖出矩形，自动创建四面隔墙并生成一个房间。 |
| FR-02-3 | 拆分房间 | 在房间内部画一道隔墙，自动识别为两个房间。 |
| FR-02-4 | 合并房间 | 删除两个房间之间的共享墙，自动合并为一个房间。 |
| FR-02-5 | 面积实时更新 | 房间面积、套内总面积、地面造价随墙体变化实时更新。 |
| FR-02-6 | 房间属性 | 可修改房间名称、地面材料、是否计入套内面积。 |
| FR-02-7 | 属性保留 | 墙体变化后，按重叠面积匹配保留原房间名称与材质。 |
| FR-02-8 | 房间标签 | 房间名称与面积显示在房间内部点，避免落在墙体或房间外。 |

### FR-03 窗户位置与尺寸

| FR-03-3 | 改宽度 | 拖动窗户两端手柄调整宽度。 |
| FR-03-4 | 改标高 | 属性面板可设置窗台高 `sill` 与窗头高 `head`。 |

### FR-05 门开方向

|---|---|---|

| FR-05-2 | 开启侧切换 | 属性面板可切换门向墙的哪一侧开启（内侧 / 外侧）。 |

### FR-06 方案管理与持久化

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-06-1 | 撤销 / 重做 | 墙体、门窗、房间编辑全部纳入现有撤销栈。 |
| FR-06-2 | 本地保存 | 编辑结果自动保存到 localStorage，刷新后恢复。 |
| FR-06-3 | 旧存档迁移 | v1 存档自动迁移为 v2 户型文档，不丢失家具与拆改记录。 |
| FR-06-4 | 导出 / 导入 | 导出的 JSON 包含完整户型；导入时校验并修复非法数据。 |
| FR-06-5 | 重置 | 重置回默认户型模板。 |

### FR-07 选择与属性面板

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-07-1 | 选择类型 | 支持选择家具、房间、墙体、门、窗、推拉门。 |

| FR-07-3 | 属性编辑 | 面板按对象类型展示对应字段。 |

| FR-07-5 | 取消 | `Esc` 取消当前绘制或清空选择。 |

### FR-08 3D 联动

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-08-1 | 几何同步 | 墙体、门窗、房间变化后 3D 建筑体同步重建。 |

## 6. 交互规则

### 6.1 工具与快捷键

| 工具 | 快捷键 | 行为 |
|---|---|---|
| 选择 | `V` | 选择、拖动、调尺寸、旋转家具 |
| 墙体 | `W` | 拖动画正交墙 |
| 房间 | `Q` | 拖矩形快速建房 |
| 门 | `D` | 点击墙体插入门 |
| 窗 | `N` | 点击墙体插入窗 |
| 推拉门 | `S` | 点击墙体插入推拉门 |
| 测量 | `M` | 两点测量 |
| 拆改 | `X` | 拆除 / 恢复墙段 |

通用：`Esc` 取消，`Delete / Backspace` 删除选中，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，`Alt` 临时关闭吸附。

### 6.2 吸附优先级

由高到低：

1. 墙体端点 / 墙角；
2. 墙面投影（贴墙）；
3. 墙体中点；
4. 门窗洞口边缘；
5. 10mm / 50mm 自适应网格。

吸附容差按屏幕像素换算（8–10px），保证任意缩放下手感一致。吸附命中时显示吸附点与参考线。

### 6.3 墙体绘制

- 默认正交：按拖动的主方向决定水平或垂直。
- 实时预览显示墙长、厚度与吸附提示。
- 默认厚度 200mm（隔墙），属性面板可切换 120 / 200 / 240mm。
- 最小墙长 100mm，小于该值不提交。

### 6.4 门窗放置

- 门窗工具下，鼠标悬停墙段高亮，显示将生成的洞口预览。
- 点击位置为洞口中心，默认尺寸：门宽 900mm，窗宽 1200mm，推拉门宽 2000mm。
- 选中门窗后，两端手柄用于改宽，主体用于沿墙拖动；两者都实时显示宽度与距墙端距离。

### 6.5 门开向操作

属性面板提供四态按钮：

```
[ 内左 ] [ 内右 ]
[ 外左 ] [ 外右 ]
```

- 「左 / 右」表示铰链靠门洞的起始端 / 结束端；
- 「内 / 外」表示门扇向墙体的一侧开启；
- 切换后 2D 弧线与 3D 门扇立即更新。

## 7. 业务规则与边界

| 规则 | 取值 / 说明 |
|---|---|
| 墙体最小长度 | 100mm |
| 墙体厚度 | 60–400mm；默认 200mm |
| 墙垛最小宽度 | 门窗洞口到墙端的最小距离 100mm |
| 门洞宽度 | 600–1200mm；默认 900mm |
| 窗洞宽度 | 300–3000mm；默认 1200mm |
| 推拉门宽度 | 800–3000mm；默认 2000mm |
| 门头高 | 默认 2100mm |
| 窗台高 | 默认 900mm；窗头高默认 2400mm |
| 洞口间距 | 同一墙线上两个洞口之间至少 100mm |
| 房间最小面积 | 0.5m²，低于该值不生成房间 |
| 房间匹配 | 新区域与原房间重叠面积最大者继承名称与材质 |
| 房间面积 | 按多边形净面积计算，单位 m²，保留两位小数 |
| 墙体移动 | 依附门窗同步移动；无法移动时夹紧并提示 |
| 墙体改长 | 不允许越过已有洞口，夹紧到最近的墙垛边界 |
| 删除门 / 窗 | 左右墙段优先合并为一段；类型不一致时保留较长的墙段类型 |
| 承重墙 | 允许编辑，但与「拆改」一样仅作为类型标识，不做工程校验 |

## 8. 非功能需求

| 编号 | 需求 | 指标 |
|---|---|---|
| NFR-01 | 精度 | 内部坐标 mm，网格 10mm；尺寸显示取整 |
| NFR-02 | 2D 性能 | 拖拽编辑保持流畅；渲染不因墙体数量线性卡顿 |
| NFR-03 | 3D 性能 | 布局提交后 3D 重建使用防抖合并，避免拖拽期间逐帧重建 |
| NFR-04 | 触屏 | 保留现有双指缩放、单指平移；编辑手柄在触屏下加大命中面积 |
| NFR-05 | 国际化 | 新增界面文案全部走 `i18n`，支持中英文 |
| NFR-06 | 兼容性 | 旧版本 localStorage 存档可迁移；导入非法 JSON 有明确提示 |
| NFR-07 | 可维护性 | 几何编辑逻辑集中在独立模块，不散落在组件事件中 |
| NFR-08 | 可验证性 | `tsc -b && vite build` 通过；核心几何操作具备单元测试或可复现手测用例 |
